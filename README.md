# Учебный модуль фитнес-трекера

Небольшой учебный Python-проект по объектно-ориентированному программированию. Модуль принимает данные датчиков, определяет тип тренировки, рассчитывает дистанцию, среднюю скорость и расход калорий, затем формирует итоговое сообщение.

Проект выполнен как учебное задание и не позиционируется как промышленная система или коммерческий продукт.

## Реализованные классы

- `Training` — базовая модель тренировки и общие расчёты;
- `Running` — расчёт показателей бега;
- `SportsWalking` — расчёт показателей спортивной ходьбы;
- `Swimming` — расчёт показателей плавания;
- `InfoMessage` — форматирование сводки о тренировке.

Функция `read_package()` сопоставляет код датчика (`SWM`, `RUN`, `WLK`) с нужным классом, а `main()` выводит результат.

## Структура

```text
.
├── homework.py           # модели тренировок и пример запуска
├── tests/                # тесты расчётов и форматирования
├── requirements.txt      # зависимости для проверки
├── pytest.ini            # настройки pytest
└── setup.cfg             # настройки статического анализа
```

## Запуск

Требуется Python 3.9 или новее.

```bash
python -m venv .venv
```

Windows:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python homework.py
```

Linux/macOS:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python homework.py
```

## Проверка

```bash
python -m pytest -q
python -m flake8 homework.py tests
```

При обновлении документации проект проверен на Python 3.11: 38 тестов проходят, flake8 не сообщает ошибок. Исходные зависимости 2021 года были несовместимы с Python 3.11, поэтому список сокращён до актуальных инструментов верхнего уровня.
